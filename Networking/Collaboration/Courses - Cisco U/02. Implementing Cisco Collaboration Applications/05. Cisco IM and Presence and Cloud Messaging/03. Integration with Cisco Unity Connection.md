Cisco Jabber clients use Cisco Unity Connection to retrieve voicemails.

![[Pasted image 20241125093051.png]]

Cisco Unity Connection can be integrated with Cisco Unified Communications Manager so that end users can access their voice mailbox in Cisco Jabber. Cisco Jabber voicemail integration uses IMAP to access the voice mailbox, which provides the following features:

- Users can access voice messages directly from the conversation history pane in the Cisco Jabber client.
- Users can play and delete messages with the integrated media player directly from the Cisco Jabber client.
- Users can easily access presence and availability information about the voicemail caller in the Cisco Jabber client. The user can click to start a phone call, web chat, video, or other multimedia session with the person.
