Cisco Jabber uses Cisco Webex for its web conferencing capability.

![[Pasted image 20241125093227.png]]

The web conferencing features of Cisco Webex use HTTP or HTTPS as the transport protocol. You can also add the Cisco TelePresence Management Suite as a video conference scheduling portal.

![[Pasted image 20241125093247.png]]

Cisco Jabber can still use Cisco Meeting Server, Cisco TelePresence Server, Cisco TelePresence MCU, and CMR Cloud for audio video conferences. In this case, Cisco Jabber uses conferencing resources that are provided by Cisco Unified Communications Manager. This scenario is the same as making a conference call from a Cisco IP phone.
