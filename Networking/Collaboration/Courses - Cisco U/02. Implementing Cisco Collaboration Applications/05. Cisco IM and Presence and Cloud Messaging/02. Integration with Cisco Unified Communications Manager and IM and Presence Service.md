Even the basic functionality of Cisco Jabber requires integration with Cisco Unified Communications Manager and IM and Presence servers. The following figure shows the communications protocols that are involved in this integration.

The SIP connection between the IM and Presence Service and Cisco Unified Communications Manager manages all phone state presence information exchanges. For these exchanges to occur, Cisco Unified Communications Manager configuration requires that the IM and Presence Service is added as an application server and that a SIP trunk points to the IM and Presence Service. The IM and Presence Service automatically manages the configuration of the Cisco Unified Communications Manager application server entry through AXL/SOAP, after you add a node in the system topology page through IM and Presence Service administration.

The Computer Telephony Integration Quick Buffer Encoding (CTIQBE) connection between the IM and Presence Service and Cisco Unified Communications Manager is the protocol that presence-enabled users use in the IM and Presence Service to control their associated phones that are registered to Cisco Unified Communications Manager. This CTI communication occurs when Cisco Jabber uses desk phone mode for Click to Call or when Skype for Business uses Click to Call through the Microsoft Skype for Business server. IM and Presence Service CTI configuration for use with Cisco Jabber is automatically created during the database synchronization with Cisco Unified Communications Manager. All Cisco Jabber CTI communication occurs directly with Cisco Unified Communications Manager and not through the IM and Presence Service.

Cisco Jabber uses SOAP to request the IM and Presence Service for system configuration. XMPP is used as a basic presence protocol between Cisco Jabber and the IM and Presence Service.
