
When you integrate Cisco Unified Communications Manager with Cisco Unity Connection via SCCP, use the Voice Mail Port Wizard in Cisco Unified Communications Manager Administration. The Voice Mail Port Wizard asks for parameters (such as the number of voicemail ports), automatically generates the voicemail ports, and puts the ports into the line group. The hunt list and hunt pilot need to be configured manually.

For the voicemail profile and voicemail pilot, use and modify the default entries that exist for all users in the Cisco Unified Communications Manager system.

When a user presses the Messages button on a Cisco IP phone, Cisco Unified Communications Manager looks up the voicemail profile that is associated with the phone line, and takes the voicemail pilot from the profile. For example, if the voicemail pilot is configured with the number 2100, then the Cisco Unified Communications Manager searches for a hunt pilot that includes the number 2100. The hunt pilot looks up its configured hunt list, which then looks up the line group. The voicemail ports are then used as defined in the line-group parameter distribution mechanism; for example, round robin.

On the Cisco Unity Connection system, the call enters via the ports that are the counterparts of the Cisco Unified Communications Manager voicemail ports. The Cisco Unity Connection ports can be configured for a specific use, such as performing message notifications (to notify users of voicemail events) or setting the MWI.

You can control call routing—that is, how calls come in and leave the Cisco Unity Connection system—via the port group or phone system.

When a caller leaves a message for a subscriber, Cisco Unity Connection notifies the phone system to activate the MWI on the subscriber’s phone which is done by turning on the red light of the phone along with a blinking message icon on the Phone. You must configure the MWI with the same numbers on both sites. For example, if you configure 2110 for MWI on and 2111 for MWI off, you must configure these same numbers on both sites. Cisco Unity Connection dials out the MWI number. The call is extended to the Cisco Unified Communications Manager, which then dials the IP phone. The MWI is turned on or off. You can also manually dial numbers to test whether the MWI numbers can reach the IP phones; CoS might prevent this behavior.

The SCCP integration uses TCP port 2000, which is the standard SCCP port. IP phones also use this port; for example, to communicate with Cisco Unified Communications Manager. The communication between the IP phone and Cisco Unity Connection can be secured (on TCP port 2443), which requires the use of certificates.
