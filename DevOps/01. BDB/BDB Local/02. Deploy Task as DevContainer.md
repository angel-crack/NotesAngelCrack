## Working Structure, Local Machine

```powershell
Projects/
├─ csom/
├─ cxsat_cocr/
├─ stepco/
├─ taskers.json
virtualEnviroment/
├─ BDBFILES/
│  ├─ BDBLIB_DBCONFIG.json
│  ├─ BDBLIB_TOKEN.json
```

Basicamente, hay dos folders **Projects** y **virtualEnviroment**.

[+] **Projects**: Contiene todas los projectos que se van a trabajar, y adicionalmente el file **taskers.json**
[+] **virtualEnviroment**: Contiene los links a las bases de datos que mas se usan y el archivo donde se guardará el token para autenticarse.

## Steps

1. Crear variables de entorno.

a. Generamos los paths a **Projects** y **virtualEnviroment/BDBFILES** ⇒ Los path deben crearse con "/" y no con "\\"

```powershell
setx BDBLIB_ALL_PROJECTS "C:/Users/aubarnes/Projects"
setx BDBLIB_JSON_FILES "C:/Users/aubarnes/virtualEnviroment/BDBFILES"
setx BDBLIB_USERNAME "aubarnes"
```

2. Dentro de cada proyecto que se va contenerizar se crea una carpeta **.devcontainer** y un archivo **.devcontainer.json** de esta manera:

```powershell, hl:3,4
Projects/
├─ csom/
│  ├─ .devcontainer/
│  │  ├─ devcontainer.json
│  ├─ All Project files
├─ cxsat_cocr/
├─ stepco/
├─ taskers.json
virtualEnviroment/
├─ BDBFILES/
│  ├─ BDBLIB_DBCONFIG.json
│  ├─ BDBLIB_TOKEN.json
```

Mounts ⇒ Aqui enlazamos los folders de nuestra maquina local con los folders dentro del container, hacemos uso de las env variables de la maquina local. Basicamente enlazamos:

a. Carpeta local de todos los proyectos a code/AllProjects
b. Carpeta local del proyecto a code/NombreProyecto
c. Carpeta local de los BDBFILES a /BDBFILES

```powershell
"runArgs": [

  ],
```
