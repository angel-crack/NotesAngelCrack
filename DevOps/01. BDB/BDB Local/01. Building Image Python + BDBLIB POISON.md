[+] The following command will create a container with python 3.11.2, that will be the python that we will use for BDB. Besides it will create a bind volume between "virtualEnviroment/BDBLIB_BDB_BUILD" from my local machine and "/BDBLIB_BDB_BUILD" from the file system of the container, allowing us to access to env.py and init.py from the container. Additionally, this command will open a shell console for the container.

``` zsh
docker run -it --rm --name bdblib_python3_11_2_container_new python:3.11.2-slim bash
```

[+] Refering to the official documentation of BDB:

[BDB Installation](https://scripts.cisco.com/doc/bdblib/tutorial.html#installing-bdblib)

```zsh
pip install -i https://scripts-pypi.cisco.com/root/pypi/+simple bdblib
```

[+] Files are contained, so we proceed to replace them.

``` zsh
cp /BDBLIB_BDB_BUILD/__init__.py usr/local/lib/python3.11/site-packages/bdblib/__init__.py
cp /BDBLIB_BDB_BUILD/env.py usr/local/lib/python3.11/site-packages/bdblib/env.py
```
