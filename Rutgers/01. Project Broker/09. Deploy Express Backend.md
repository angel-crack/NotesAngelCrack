Create directory for saving the data

```bash
mkdir -p /home/ruadmin/app/backend
```

Deploy container

```bash
podman run -it -p 3000:3000 --name "DevAppBackend" -v "/home/ruadmin/app/backend":"/app/Backend" node-express
```

Go to folder project and serve Application

```powershell
ng serve --host 0.0.0.0 --poll=2000
```
