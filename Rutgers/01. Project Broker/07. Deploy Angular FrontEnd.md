Create directory for saving the data

```bash
mkdir -p home/ruadmin/app/frontend
```

Deploy container

```bash
podman run -d -p 4200:4200 --name DevAppFrontend -v /home/ruadmin/app/frontend:/app/Front node-angular
```

Go to folder project and serve Application

```powershell
	ng serve --host 0.0.0.0 --poll=2000
```
