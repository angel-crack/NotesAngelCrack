Create a "Container" file

```Dockerfile
FROM node:20.11.1

# Set the working directory
WORKDIR /app/Backend

# Install Angular CLI globally
RUN npm install express

# Install Git
RUN apt-get update && apt-get install -y git && rm -rf /var/lib/apt/lists/*

# Set default command
CMD ["bash"]
```

Create folder structure

```bash
/home/ruadmin/Documents/Container Files/
```

Create "Express" folder, and paste Containerfile

```bash
podman build -t node-express -f Containerfile .
```

Save the image for backup:

```bash
podman save -o node-express.tar node-express
```
