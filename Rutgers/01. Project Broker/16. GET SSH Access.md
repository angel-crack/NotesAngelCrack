On Local machine

```bash
ssh-keygen -t rsa -b 4096 -f C:\Users\aubarnes\.ssh\id_rsa
```

then copy the content and paste it in the following file on the remote machine

```bash
~/.ssh/authorized_keys
```

```bash
Host 1APP_Prod
```
