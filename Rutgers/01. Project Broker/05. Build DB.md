Create directory for saving the data

```bash
mkdir -p home/sftp-box/app/mongo_cdr_data
```

Deploy the container with the volume bind to mongo_data

```bash
podman run -d --name DevAppDatabase --network host -e MONGO_INITDB_ROOT_USERNAME=admin -e MONGO_INITDB_ROOT_PASSWORD=secret -v /home/sftp-box/app/mongo_cdr_data:/data/db docker.io/library/mongo:latest

```

Login as 

```powershell
mongodb://admin:secret@10.224.71.196:27017/?authSource=admin
```
