# API Usage Guide

## Step 1: Authenticate to Get Token

Send a `POST` request to the `/api/auth` endpoint with `userId` and `password` using `x-www-form-urlencoded`:

```bash
curl --location 'https://one01-3567-psc.eitc.rutgers.edu:3000/api/auth' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'userId=<USERNAME>' \
--data-urlencode 'password=<PASSWORD>'
```

✅ Example Response

```json
{
    "jwToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9"
}
```

## Step 2: Make Authenticated Requests

Use the `jwToken` from the previous response in the `Authorization` header as a Bearer token.

###  Example Request (Without Pagination)

If **no pagination parameters** are included, the endpoint will return the first page of results by default:

```bash
`curl --location 'https://one01-3567-psc.eitc.rutgers.edu:3000/userNumber/msTeams' \ --header 'Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9'`
```

##  Step 3: Pagination Support (Optional)

You can now paginate the `/userNumber/msTeams` endpoint using query parameters:

- `page`: The page number to retrieve (default is 1).
- `limit`: How many items per page (default is 10).

###  Example Request (With Pagination)

```bash
`curl --location 'https://one01-3567-psc.eitc.rutgers.edu:3000/userNumber/msTeams?page=2&limit=3' \ --header 'Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9'`
```

✅ Example Paginated Response

✅ **Summary**:
- **Without pagination parameters**: The response will be paginated with **page 1** by default.
