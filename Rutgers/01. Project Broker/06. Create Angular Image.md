Create a "Container" file

```Dockerfile
FROM node:20.11.1

# Set the working directory
WORKDIR /app

# Install Angular CLI globally
RUN npm install -g @angular/cli

# Install Git
RUN apt-get update && apt-get install -y git && rm -rf /var/lib/apt/lists/*

# Set default command
CMD ["bash"]
```

Create folder structure

```bash
/home/ruadmin/Documents/Container Files/
```

Create "Angular" folder, and paste Containerfile

```bash
podman build -t node-angular -f Containerfile .
```

Save the image for backup:

```bash
podman save -o node-angular.tar node-angular
```
