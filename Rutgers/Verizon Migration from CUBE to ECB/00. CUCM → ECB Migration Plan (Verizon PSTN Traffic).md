Gradually migrate outbound PSTN traffic currently routed from **CUCM → CUBE-VZ** to **CUCM → ECB** with minimal risk, clear rollback, and measurable validation—starting with the highest-volume patterns first.

## ~={blue}03. Data-Driven Scope (last 30 days)=~

We’ll analyze the last **30 days** of CDR and filter calls where the final hop device is either:

- `trk-ru-psc-cube-vz`
- `trk-cube01-8725-nwk_Verizon`

**Reference – CDR Field**  
From [CDR Fields](https://www.cisco.com/c/en/us/td/docs/voice_ip_comm/cucm/callReportingBillingAdmin/14/cucm_b_reporting-billing-administration-guide-14/cucm_b_reporting-and-billing-administration-guide_chapter_01010.html#reference_0E8289FAF623FDDA5C31744726F963F6): `destDeviceName` = “name of the destination device.” (default empty if unnamed)

| destDeviceName | Text String | Specifies the text string that identifies the name of the destination device.<br><br>Default - Empty string"". If the original device does not have a name, this field stays empty. |
| -------------- | ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

Upon retrieval of the 30-day CDR dataset from the billing server, the filtering script below will be executed to produce the filtered call records.


```python
# Output file
output_file = "filtered_cdr_rows.txt"
# Target values to filter (as a list)
target_numbers = ["trk-ru-nwk-cube-vz", "trk-ru-psc-cube-vz"]  # Add all numbers you want to match
# Open the output file to write filtered lines
with open(output_file, "w") as out_file:
    for file_name in input_files:
        with open(file_name, "r") as in_file:
            for line in in_file:
                try:
                    data = json.loads(line.strip())  # Parse JSON
                    dest_device = data.get("destDeviceName", "")
                    if dest_device in target_numbers:
                        out_file.write(json.dumps(data) + "\n")  # Write matching line
                except json.JSONDecodeError:
                    print(f"Skipping invalid JSON in file: {file_name}")
print(f"✅ Filtering complete! Results saved in {output_file}")
```
