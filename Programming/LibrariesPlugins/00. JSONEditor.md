## Angular Installation

```powershell
root@8dddf9e8bd8c:/code/Angular17/ngApp17# npm install jsoneditor 

root@8dddf9e8bd8c:/code/Angular17/ngApp17# npm install --save-dev @types/jsoneditor 
```

under tsconfig.json add:

```json
"compilerOptions": {
    "typeRoots": [
      "node_modules/@types"
    ],
    "types": [
      "jsoneditor"
    ]
}
```

under angular.json we will have:

```json
{
"styles": [
	  "src/styles.css",
	  "./node_modules/jsoneditor/dist/jsoneditor.min.css"
		],
"scripts": [
	  "./node_modules/jsoneditor/dist/jsoneditor.min.js"
		]
}
```

Once we have installed the packages and added the min css and js, we can go to the component and add

```ts
import JSONEditor from 'jsoneditor';
```

On HTML create the div that will containe the JSONEditor and assign a [[15. ngTemplate; Context{}]] ⇒ Reference Template

```html
<div #jsoneditor style="width: 70vw; height: 400px;"></div>
```

And we use:

```ts
export class AppComponent implements AfterViewInit {
  @ViewChild('jsoneditor') jsonEditorElement!: ElementRef;
  editor!: JSONEditor;
  
  initialJson: any = {
    "Array": [1, 2, 3],
    "Boolean": true,
    "Null": null,
    "Number": 123,
    "Object": {"a": "b", "c": "d"},
    "String": "Hello World"
  };
  
  ngAfterViewInit() {
    // Get the DOM element from ViewChild
    const container = this.jsonEditorElement.nativeElement;
    
    // Create the editor instance
    const options = {};
    this.editor = new JSONEditor(container, options);

    // Set initial JSON
    
    this.editor.set(this.initialJson);
  }

}
```
