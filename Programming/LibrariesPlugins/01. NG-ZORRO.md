Add the NG Zorro:

```powershell
$ ng add ng-zorro-antd
```

![[Pasted image 20241218084745.png]]

On angular JSON you will see:

```powershell
"styles": [
              "./node_modules/ng-zorro-antd/ng-zorro-antd.min.css",  => Here
              "src/styles.scss"
            ],
```

to enable dark mode, on style.css || style.scss

```powershell
@import "../node_modules/ng-zorro-antd/ng-zorro-antd.dark.min.css";
```

======

Icon Usage

```ts
import { provideNzIcons } from 'ng-zorro-antd/icon';
import { DownloadOutline } from '@ant-design/icons-angular/icons';
import { IconDefinition } from '@ant-design/icons-angular';


registerLocaleData(en);
const icons: IconDefinition[] = [ DownloadOutline ];


export const appConfig: ApplicationConfig = {
  providers: [
    provideZoneChangeDetection({ eventCoalescing: true }), 
    provideRouter(routes), 
    provideNzI18n(en_US), 
    importProvidersFrom(FormsModule), 
    provideAnimationsAsync(), 
    provideHttpClient(),
    provideNzIcons(icons)
  ]
};
```
