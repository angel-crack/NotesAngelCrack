## What are Development Containers?

A development container (or dev container for short) allows you to use a container as a full-featured development environment. It can be used to run an application, to separate tools, libraries, or runtimes needed for working with a codebase, and to aid in continuous integration and testing.


https://containers.dev/implementors/json_reference/

We will start from the structure:

```
baseProject/
├─ .devcontainer/
│  ├─ devcontainer.json
│  ├─ Dockerfile
├─ index.py
```

[+] devcontainer.json ⇒ Store VS Code's container configuration.

We can start with:

```json
{
  "name": "${localWorkspaceFolderBasename}",
  "dockerFile": "./Dockerfile"
}
```

- We will use the following [attributes](https://containers.dev/implementors/json_reference/#general-properties)
- We can use some [variables](https://containers.dev/implementors/json_reference/#variables-in-devcontainerjson)

Dockerfile ⇒ Build the image of the container to be used.
