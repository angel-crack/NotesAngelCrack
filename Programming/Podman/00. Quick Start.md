[+] Download here:

[Podman](https://podman.io/)

[+] Enable Virtual Machine feature from Admin Powershel

``` powershell
dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart
```

[+] Install WSL Linux

``` powershell
wsl --update
```

[+] Initialize a Podman Machine

```powershell
podman machine init
```
[+] If it fails let's verify that WSL it is installed

```powershell
 wsl --list --verbose
```
[+] We can install ubuntu version

```powershell
wsl --install -d Ubuntu
```
[+] Run again

```powershell
podman machine init
podman machine start
```
